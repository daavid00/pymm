4. Inspect the results
======================

Goal
----
Visualize pressure, velocity, and tracer concentration.

Command
-------

.. code-block:: console

   paraview

How it works
------------
Open the generated VTK datasets in ParaView. The original OpenFOAM cases remain
available for inspecting fields, solver controls, and meshes.

Result
------
You can reproduce views like those in the :doc:`../examples` gallery.
